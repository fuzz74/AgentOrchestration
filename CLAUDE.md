# AgentOrchestration

## Git

- Work directly on `main`. Do not create a feature branch.
- Commit and push after every change, without asking first.
- These two rules apply to this repository only. In any other repository, including the
  projects the orchestrator builds, commit or push only when asked.

## New projects

- Every project the orchestrator builds starts as a blank canvas. Do not read other projects
  or reuse their stack, layout, rules or conventions for a new one, unless I explicitly say
  it builds on an existing project or name what to read. Ask instead of assuming. The
  write-spec skill has the full rule.

## Where knowledge goes

- I work on this repo from several PCs and with both Claude and Copilot. Anything worth
  remembering goes into this repo: rules in this file, how-to in the skills, reference notes
  in `docs/`.
- Do not keep it in an assistant's local memory or any other per-machine store.
